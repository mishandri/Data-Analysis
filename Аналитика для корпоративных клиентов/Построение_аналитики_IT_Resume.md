
## IT-Resume: аналитика для корпоративных клиентов

- **Проблема:** Корпоративным клиентам платформы IT Resume требовалась аналитика по активности сотрудников: сколько задач решают, кто лидирует, какие задачи вызывают сложности. Отсутствовала автоматизированная отчетность.
- **Решение:** Построен аналитический конвейер на SQL. Данные из таблиц codesubmit, coderun и users объединены, агрегированы и подготовлены для отчетности. Написаны оптимизированные запросы с CTE, UNION ALL и оконными функциями.
- **Что сделано:**
  1. Анализ codesubmit: подсчет уникально решенных задач для компании с id = 1, рейтинг пользователей по количеству решенных задач, расчет среднего количества задач на пользователя через CTE.
  2. Анализ coderun + codesubmit: объединение таблиц через UNION ALL, подсчет количества решений по каждой задаче, топ-5 задач по среднему количеству попыток (тип cr — code run), анализ задач с наибольшим количеством попыток.
- **Стек:** SQL (PostgreSQL), CTE, UNION ALL, агрегация, фильтрация по типам попыток.
- **Результат:** Автоматизирована подготовка аналитических данных для корпоративных клиентов. Отчетность показывает активность сотрудников, рейтинги по задачам и позволяет выявлять самые сложные/популярные задачи.
