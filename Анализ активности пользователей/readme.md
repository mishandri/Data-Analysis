# Анализ активности пользователей платформы обучения

Python, Pandas, Seaborn. Логи запусков и отправки решений, регистрации и входы пользователей. Период с ноября 2021 по февраль 2022.

Работа в формате ad-hoc: строится график, к нему даётся набор утверждений, часть из них верные, остальные нет. Задача отсеять лишнее.

## Вопрос 1. Динамика попыток и среднее

Верно: пик активности пришёлся на январь-февраль 2022, было несколько дней со значением больше 800 попыток.

Не подтвердилось: устойчивый рост с течением времени, равномерные единичные попытки до ноября 2021, отсутствие просадок ниже среднего после ноября.

Вывод: платформа не росла плавно, был сезонный всплеск. Средние по всему периоду не описывают типичный день.

## Вопрос 2. Распределение попыток по языкам

Boxplot по дневному количеству попыток с разбивкой на `language_id` 2 и 3.

Верно: у языка с ID 2 заметно большая вариативность, в одни дни попыток мало, в другие очень много. По графику нельзя сказать, в какой группе больше измерений. Объём хвоста выше 25-го перцентиля у ID 2 сопоставим с объёмом ниже 75-го перцентиля у ID 3.

Не подтвердилось: равенство максимумов, прямая связь максимума с числом выбросов, большее среднее у ID 2.

## Вопрос 3. Помесячная эволюция

Boxplot по месяцам с декабря 2021, внутри месяца разбивка по языкам.

Верно: в последнем месяце вариативность дневного количества попыток резко упала в обеих группах.

Не подтвердилось: одинаковый темп изменений в обеих группах, рост межквартильного разброса у ID 2, заметно меньшее число измерений в последнем месяце.

## Вопрос 4. Дата регистрации и число решённых задач

Диаграмма рассеяния.

Верно: линейной связи нет. Основная масса пользователей решила до 20 задач. Внутри каждой сотни есть отдельные люди с аномально высоким результатом, и среди зарегистрировавшихся позже таких меньше.

Не подтвердилось: выраженная линейная связь, обратная зависимость.

Гипотеза в линейной форме не подтвердилась, но сигнал есть: у свежих когорт ниже потолок активности. Проверять стоит по сегментам, а не одним трендом.

## Вопрос 5. Корреляции признаков сложности

Матрица корреляций для среднего, максимального и минимального количества попыток на задачу.

Верно: при пороге сильной корреляции 60% есть минимум две связанные пары. Слабая корреляция ровно одна пара. Среднее количество попыток примерно одинаково коррелирует и с максимумом, и с минимумом.

Не подтвердилось: несколько слабых корреляций, признаки с корреляцией 100%, сильная обратная зависимость.

Вывод: признаки связаны между собой умеренно, поэтому один нельзя считать прокси другого. Для модели сложности нужны все три.

## Вопрос 6. N-day retention по когортам

Когорта это месяц решения первой задачи, взяты только когорты с ноября 2021. График строится по количеству уникальных пользователей в каждый n-й день до 30-го, а не по проценту удержания.

Верно: ранние когорты удерживаются лучше в долгосрочной перспективе, у ряда когорт нестандартная форма кривой, удержание слабое и к 10-му дню кривые почти уходят в ноль.

Не подтвердилось: одинаковый размер когорт, эффект email-рассылки на 5-й день, постоянная интенсивность использования у когорты января на 20-й день.

Главная проблема здесь не привлечение, а удержание. На десятый день возвращаются единицы, значит приоритет смещается с трафика на активацию в первые дни.

## По визуализации

Равномерность выборок сравнивалась через boxplot, распределения с наложенными хвостами через violinplot. Отдельно строился график по неделям и месяцам, чтобы проверить, действительно ли распределения равномерны.

## Замечание

График по количеству уникальных пользователей в каждый n-день и график retention в процентах показывают разное. Первый сравнивает когорты разного размера напрямую, второй нормализует. Для выводов об удержании это две разные картины, и путать их не стоит.
