# Дашборд KPI аптечной сети

Apache Superset поверх PostgreSQL. Данные чеков аптечной сети: продажи, чеки, номенклатура, аптеки, типы скидок. На скриншотах период апрель-июнь 2022.

## Устройство дашборда

Обзор с верхнеуровневыми KPI, детализация с построчной расшифровкой и сводная таблица для выгрузки.

## Обзор

| Показатель | Значение | Динамика |
|------------|----------|----------|
| Продажи | 1.35M | −31.6% |
| Средний чек | 285.41 | +3.0% |
| Аптек в сети | 8 | без динамики |

Продажи в динамике: 2.06M в начале мая, просадка до 1.69M, пик 2.16M в середине, возврат к 1.97M к концу. Средний чек повторяет тот же контур.

Отдельно стоит панель «Тип скидки»:

| Тип | Продажи | Доля |
|-----|---------|------|
| Без скидки | 6.39M | 54.86% |
| Пенсионный дисконт | 2.67M | 22.90% |
| Аптека №3 | 1.41M | 12.08% |
| Парус | 773K | 6.64% |
| Акции | 193K | 1.66% |

Дальше идёт длинный хвост мелких типов, которые в сумме дают заметную долю. В отчёте по выручке они не видны, поэтому срез по скидкам нужен отдельной панелью.

Топ-5 аптек по продажам: от 2.36M у лидера до 1.33M на пятом месте.

## Детализация

Таблица построчных продаж с сортировкой и поиском: дата, номер чека, тип продаж, аптека, наименование препарата, количество, цена. Через поиск можно ответить на вопрос про конкретный препарат, не выходя из дашборда.

## Про разбивку на вкладки

На обзорной вкладке три числа и их разложение: динамика, срез по аптекам, срез по скидкам. Всё остальное туда не влезает без потери читаемости. Детализация включается по требованию, сводная таблица нужна для работы вне дашборда.

Если смешать всё на одной странице, получится длинная лента, где верхний экран уедет на графики и три ключевые цифры перестанут быть видны сразу.
